# AlinCode 桌面聊天三栏布局验收 Checklist

> 每项必须以构建输出、实际界面观察或真实交互验证；不得仅凭阅读代码勾选。

## 会话环境

- [ ] 收到当前会话的 `session.info` 后，界面显示该会话返回的模型和项目目录。（验证：启动桌面端并观察中栏标题和右栏与后端会话信息一致。）
- [ ] 切换历史会话后，显示的会话、模型和目录不会残留上一会话的数据。（验证：切换两个有不同目录或模型的会话并观察右栏。）

## 三栏布局

- [ ] Windows 桌面窗口中同时呈现左侧导航、中间聊天、右侧环境栏，且中栏为最大区域。（验证：在默认桌面窗口截图或肉眼观察。）
- [ ] 左栏显示透明 A Logo、AlinCode、当前 Profile、新建对话和仅当前 Profile 的历史。（验证：创建或解锁 Profile 后观察，并切换 Profile 对比。）
- [ ] 「新建对话」和历史切换继续调用现有会话行为。（验证：分别点击，观察新会话与恢复的历史消息。）
- [ ] 中栏的设置按钮仍能打开、关闭并保存已有设置。（验证：修改一个非密钥设置并确认重启/刷新后生效。）

## 环境栏与本地额度

- [ ] 右栏显示真实连接状态、模型、协议、项目目录、本地 token 用量和预算状态。（验证：配置 Provider 和目录后发送真实请求，逐项与设置和状态事件对照。）
- [ ] Provider 未配置或读取失败时，右栏显示「未配置」，不显示 API Key。（验证：使用未配置 Profile 或阻断请求，检查 DOM 与可见文字。）
- [ ] 未选择目录时，右栏显示「尚未选择项目目录」。（验证：新 Profile 未填写目录进入聊天页。）
- [ ] 预算为 `0` 时显示「未设置上限」且没有伪造比例；正预算时才显示已用量与比例。（验证：分别设置 `0` 和正整数预算后刷新页面。）
- [ ] 右栏不展示其他 Profile 的模型、目录、额度或 API Key。（验证：创建两个有不同设置的 Profile，锁定并切换后对比右栏。）

## 聊天行为与视觉

- [ ] 用户消息为低饱和蓝色气泡，助手消息保持无气泡阅读面，工具和审批仍可按原有方式展开或操作。（验证：发起会触发工具和审批的真实请求，检查各类消息。）
- [ ] Enter 发送、Shift+Enter 换行、取消运行中轮次均保持可用。（验证：分别执行三种键盘/按钮操作并观察结果。）
- [ ] 页面使用已确认的深海蓝配色和透明 A Logo；没有白色 Logo 背板、Codex 品牌元素或未实现导航项。（验证：桌面端视觉检查。）
- [ ] 窗口变窄时优先保留中栏和左栏；小于 900 px 时右栏隐藏，不出现水平溢出。（验证：拖动窗口到 1100 px 和 899 px 左右宽度观察。）
- [ ] 所有键盘可达按钮与输入框有可见焦点。（验证：使用 Tab 遍历新建对话、历史、设置、输入与发送。）
